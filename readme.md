# Pixelstar

Pixelstar — це веб-додаток, який дозволяє користувачам взаємодіяти з інтерактивною сіткою, зафарбовувати клітинки різними кольорами та спілкуватися в реальному часі через чат. Проєкт підтримує авторизацію через Google та зберігає дані користувачів у базі даних SQLite.

## ⚡ Функціонал

### 🎨 Інтерактивна сітка

Користувачі можуть зафарбовувати клітинки сітки обраними кольорами.

Обмеження на частоту зафарбовування клітинок (1 хвилина між діями).

Дані про зафарбовані клітинки зберігаються в базі даних.

### 💬 Чат у реальному часі

Відправка повідомлень усім користувачам або приватних повідомлень конкретному користувачу.

Відображення списку онлайн-користувачів.

### 🔐 Авторизація

Авторизація через Google OAuth 2.0.

Реєстрація та вхід через локальні облікові записи.

### 🏆 Таблиця Лідерів

Відображення рейтингу користувачів за кількістю зафарбованих клітинок.

# 🚀 Встановлення

### 1️⃣ Клонування репозиторію

### 2️⃣ Встановлення залежностей
```bash
 npm install
```
### 3️⃣ Налаштування бази даних

У папці db/ створіть файл users.db.

SQLite автоматично створить необхідні таблиці при запуску сервера.

### 4️⃣ Налаштування Google OAuth 2.0

**Створіть файл config/client_secret.json і додайте ваші облікові дані Google API:**
**В такому вигляді**
```js
{
  "web": {
    "client_id": "YOUR_GOOGLE_CLIENT_ID",
    "project_id": "YOUR_PROJECT_ID",
    "auth_uri": "https://accounts.google.com/o/oauth2/auth",
    "token_uri": "https://oauth2.googleapis.com/token",
    "auth_provider_x509_cert_url": "https://www.googleapis.com/oauth2/v1/certs",
    "client_secret": "YOUR_GOOGLE_CLIENT_SECRET",
    "redirect_uris": ["http://localhost:3000/auth/google/callback"]
  }
}
```
### 5️⃣ Запуск сервера
```bash
npm start
node server.js
```
**Сервер буде запущено на http://localhost:3000.**

## 🎮 Використання

### 🖌️ Інтерактивна сітка

Авторизуйтесь через Google або зареєструйтесь.

Виберіть колір у палітрі.

Натисніть на клітинку сітки, щоб зафарбувати її.

### 💬 Чат

Введіть повідомлення у поле вводу.

Натисніть кнопку "Відправити", щоб надіслати повідомлення всім користувачам або виберіть конкретного користувача для приватного повідомлення.
