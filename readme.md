# Pixelstar

Pixelstar — це веб-додаток, який дозволяє користувачам взаємодіяти з інтерактивною сіткою, зафарбовувати клітинки різними кольорами та спілкуватися в реальному часі через чат. Проєкт підтримує авторизацію через Google та зберігає дані користувачів у базі даних SQLite.

---

## ⚡ Функціонал

### 🎨 Інтерактивна сітка
- Користувачі можуть зафарбовувати клітинки сітки обраними кольорами.
- Обмеження на частоту зафарбовування клітинок (1 хвилина між діями).
- Дані про зафарбовані клітинки зберігаються в базі даних.
- Динамічне оновлення сітки для всіх користувачів у реальному часі.

### 💬 Чат у реальному часі
- Відправка повідомлень усім користувачам або приватних повідомлень конкретному користувачу.
- Інтерактивний інтерфейс із підтримкою WebSocket для миттєвого обміну повідомленнями.
- Підтримка приватних повідомлень із зазначенням отримувача.

### 🔐 Авторизація
- Авторизація через Google OAuth 2.0.
- Реєстрація та вхід через локальні облікові записи.
- Захист даних користувачів за допомогою Passport.js.

### 🏆 Таблиця Лідерів
- Відображення рейтингу користувачів за кількістю зафарбованих клітинок.
- Можливість переглядати свою статистику та досягати нових вершин разом із досягненнями.

### 🏅 Досягнення
- Система досягнень для мотивації користувачів:
  - Зафарбувати 100 клітинок.
  - Використати 3 різні кольори.
  - Провести 1 годину на сайті.
- Прогрес досягнень відображається у вигляді смуг прогресу.

# 🚀 Встановлення

### 1️⃣ Клонування репозиторію

### 2️⃣ Встановлення залежностей
```bash
 npm install
```
### 3️⃣ Налаштування бази даних

У папці db/ створіть файл users.db.
За допомогою команди:
```bash
 node init_grid.js
```

SQLite автоматично створить необхідні таблиці при запуску сервера.

### 4️⃣ Налаштування Google OAuth 2.0

**Створіть папку config в головній деректорії і додайте файл client_secret.json [файл QAuth](config/client_secret.json) і заповніть його вашими обліковими даними Google API:**
**В такому вигляді**
```js
{
  "web": {
    "client_id": "YOUR_GOOGLE_CLIENT_ID",
    "project_id": "YOUR_PROJECT_ID",
    "auth_uri": "https://accounts.google.com/o/oauth2/auth",
    "token_uri": "https://oauth2.googleapis.com/token",
    "auth_provider_x509_cert_url": "https://www.googleapis.com/oauth2/v1/certs",
    "client_secret": "YOUR_GOOGLE_CLIENT_SECRET",
    "redirect_uris": ["http://localhost:3000/auth/google/callback"]
  }
}
```
### 5️⃣ Запуск сервера
```bash
npm start
node server.js
```
**Сервер буде запущено на http://localhost:3000.**

## 🎮 Використання

### 🖌️ Інтерактивна сітка
1. Авторизуйтесь через Google або зареєструйтесь.
2. Виберіть колір у палітрі.
3. Натисніть на клітинку сітки, щоб зафарбувати її.

### 💬 Чат
1. Введіть повідомлення у поле вводу.
2. Натисніть кнопку "Відправити", щоб надіслати повідомлення всім користувачам або виберіть конкретного користувача для приватного повідомлення.

## 🛠️ Технології

### Back-end:
- **Node.js** — серверна платформа.
- **Express.js** — веб-фреймворк для створення API.
- **WebSocket** — для чату в реальному часі.
- **SQLite** — легка реляційна база даних.
- **Passport.js** — для авторизації через Google OAuth 2.0.

### Front-end:
- **HTML5** — структура сторінки.
- **CSS3** — стилізація інтерфейсу.
- **JavaScript (Vanilla)** — динамічна взаємодія з користувачем.
